# РТК CRM · ИТ Школа Ростелекома

Рабочий демонстрационный стенд для ведения партнёрств с вузами, индивидуального и корпоративного обучения. В одной активности собраны ответственный, стадия, следующий шаг, задачи и история; учебные факты остаются в LMS.

### Локальный запуск

Нужны Docker с Compose, Node.js 22+, npm и OpenSSL. На macOS или Linux из корня репозитория выполните:

```bash
cd crm
./run-local.sh
```

Скрипт создаст локальные пароли в `crm/.env.local`, поднимет PostgreSQL и Keycloak, применит миграции, создаст тестовые роли и запустит API, CMS/LMS-заглушки и веб-интерфейс. Откройте `http://localhost:5173`; документация API — `http://localhost:3001/docs`. Локальные логины: `kam.anna`, `kam.dmitry`, `manager`, `admin`; их пароли находятся в соответствующих переменных `KAM_ANNA_PASSWORD`, `KAM_DMITRY_PASSWORD`, `MANAGER_PASSWORD`, `LOCAL_ADMIN_PASSWORD` файла `crm/.env.local`. Они отличаются от паролей публичного стенда. Остановка приложения — `Ctrl+C`; подробности и повторный запуск — в [инструкции CRM](crm/README.md#запуск).

## Что работает

- Три отдельных маршрута: вузовское партнёрство, индивидуальное и корпоративное обучение. Для вузов есть контрольные пункты U01–U14; для компании — план готовой программы, адаптации или новой разработки.
- Роли КАМ, руководителя и администратора с серверной проверкой области доступа. Руководитель видит командный портфель и страницу «Команда» с лентой обновлений, может переназначить активность с предпросмотром; роль администратора сама по себе не открывает бизнес-карточки.
- Очереди, задачи, история, внутренние уведомления, вложения и адаптивная раскладка. КАМ получает уведомление о назначенной ему заявке; внешние сообщения не отправляются.
- Раздел «Обучение» объединяет справочник этапов и краткий каталог продуктов и программ с материалами для работы с клиентами.
- Отчёты по доступным данным CRM с фильтрами, детализацией и файлами XLS, XLSX, CSV, PDF, JSON и PNG. Заявленные места, события LMS и активности считаются разными сущностями.
- Импорт с предпросмотром, проверкой и явным подтверждением: XLS/XLSX/CSV для контактов и поставщиков; JSON/CSV для индивидуальных заявок.
- Тестовые двусторонние сценарии обмена с локальными CMS/LMS mock. Принятый запрос LMS не считается зачислением или завершением обучения.

## Границы стенда

Данные стенда демонстрационные. CMS и LMS — локальные тестовые сервисы; системы и API заказчика не подключены. Текущие стадии и инструкции отражают проектную модель, а не подтверждённый внутренний регламент. Мобильная версия и форма адаптируются к узкому экрану. Сборка сама по себе не подтверждает промышленную готовность, юридическое соответствие или полноту внешних данных.

Код и локальный запуск находятся в [`crm/`](crm/README.md). Документы о [продуктовой модели](crm/docs/PRODUCT.md), [интеграциях](crm/docs/INTEGRATIONS.md) и [проверках и ограничениях](crm/docs/QUALITY.md) дают технические подробности.
