# РТК CRM · ИТ Школа Ростелекома

Решение команды Futura для ЛЦТ 2026: CRM для партнёрств с вузами, индивидуального и корпоративного обучения. В одной активности собраны ответственный, стадия, следующий шаг, задачи, история и связанные программы. Учебный процесс остаётся в LMS.

Для просмотра внутренних ролей нужны выданные команде проверки учётные записи; пароли в репозитории не публикуются. Публичная форма доступна без входа.

## Что в репозитории

- `crm/` — React/TypeScript интерфейс, Fastify API, PostgreSQL, Keycloak, тесты и инструкции запуска.
- `Documentation/` — краткое описание решения и его границ для жюри.
- `Presentation/` — презентация в шаблоне ЛЦТ и сведения о её готовности.

CMS и LMS представлены тестовыми HTTP-контурами; подключения к системам заказчика нет. Для работы с реальными персональными данными нужны отдельные проверки правового основания, инфраструктуры и защиты.
