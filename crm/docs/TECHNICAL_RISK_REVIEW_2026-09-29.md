Изучена `.agent/jury-review/ASSESSMENT_2026-09-28.md` и текущий код. В рабочий снимок перенесены существовавшие незакоммиченные изменения для проверки совместимости; они не включены в этот коммит. P0 в проверенном сценарии не обнаружен; это не полный аудит приложения.

## Границы изменений и поддержка

Рабочая логика изменена только в `web/public/request/request.js` и `api/src/public-demo-intake.ts`. Тест браузерного скрипта находится в `api/test/public-request.test.ts`; интеграционные случаи добавлены в существующий последовательный набор `api/test/postgres.integration.test.ts`, чтобы временное изменение тестового каталога не пересекалось с его другими тестами.

Комментарии объясняют причины сохранения ключа и ограничения назначения новой организации. Новых зависимостей, слоёв архитектуры и миграций нет. Figma, импорт, «Команда», визуализации и чужие изменения в коммит не входят. Размер крупных модулей сам по себе не объявлен P1. Предположение старой оценки о JWT audience не подтвердилось: `app.ts` уже проверяет issuer/audience/azp; негативные случаи `bearer-auth.test.ts` проходят.

## Регрессия и воспроизводимость

Среда: Node 25.6.1, npm 11.9.0, PostgreSQL 17 в двух отдельных локальных Docker-контейнерах, данные PostgreSQL в tmpfs. Зависимости взяты из имеющейся локальной установки. Проверка чистой установки зависимостей из сети не выполнялась.

- **Текущий снимок + правки:** 33 миграции; `npm test` с `CRM_INTEGRATION=1` — **127 passed, 0 failed, 0 skipped**.
- **Чистый состав коммита без чужих изменений:** собственные 32 миграции на пустой второй БД; тот же полный прогон — **124 passed, 0 failed, 0 skipped**. Разница в числе тестов связана с существующими незакоммиченными тестами исходного снимка.
- **Оба снимка:** `npm run build:public` — exit 0, проверка публичных origins и итогового артефакта пройдена. Это штатная сборка проекта: TypeScript API, Vite и проверки артефакта; отдельный typecheck всего React не заявляется.
- Проверка JS формы исполняет фактический браузерный скрипт в Node VM с контролируемыми DOM, транспортом и часами. Это проверка поведения скрипта, не визуальный браузерный E2E.
- Публичные данные и инфраструктура не изменялись. Seed, деплой и push не выполнялись.
