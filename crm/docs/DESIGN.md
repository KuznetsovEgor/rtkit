# Дизайн и текущая реализация

Сверка десяти кадров Gate B с локальным индексом, кодом SPA и сохранёнными Atomaro-derived токенами. Идентификаторы и превью сверены с [индексом кадров](../../design/gate-b/gate-b-ten/index.json). Короткий судейский вход — [12 маршрутов](../../design/gate-b/START_HERE.html): на текущей странице Figma 15 основных и 6 вспомогательных кадров, остальные связанные примеры вынесены в архив файла. Приложение сейчас открывается по `/`; рабочие представления переключаются состоянием React внутри `App`, это не отдельные URL-маршруты. PNG — локальные кадры макета, не снимки запущенного приложения.

Владелец согласовал предъявленную компактную редакцию Gate B: 12 маршрутов, 15 основных и 6 вспомогательных кадров. Старые статусы отдельных критериев в локальной матрице относятся к технической полноте и не отменяют это решение. Согласование макета не подтверждает визуальную/клавиатурную проверку работающего приложения. Подробные состояния и evidence остаются в [матрице покрытия](../../design/gate-b/coverage.md).

## Токены и адаптивность

Навигация 28.09 точечно сверена с раскрытым кадром [145:1210](https://www.figma.com/design/kTMqGGpBwiPckoJk5VxCBo?node-id=145-1210): в desktop CSS уточнены вертикальный ритм заголовка, отступы пунктов 12 px, насыщенность подписей и активный цвет из сохранённого Atomaro-derived secondary-accent токена. Для свёрнутого [145:1636](https://www.figma.com/design/kTMqGGpBwiPckoJk5VxCBo?node-id=145-1636) добавлен desktop-переключатель 220/76 px с доступным именем и сохранением предпочтения; текущая карточка и её черновики при переключении не размонтируются. Мобильная нижняя навигация — отдельный сценарий и не менялась. Frontend TypeScript и сборка прошли; визуальная и клавиатурная проверка runtime остаётся открытой.

Сохранённые значения находятся в [CSS-токенах приложения](../web/src/atomaro-tokens.css); исходный снимок с номерами строк — в [atomaro-tokens.json](../../design/gate-a/evidence/atomaro-tokens.json). Локальная копия токенов нужна для самостоятельной сборки папки `crm/` без соседнего каталога `design/`. [ATOMARO_MAPPING.md](../../design/gate-b/ATOMARO_MAPPING.md) связывает отдельные источники с локальными Figma components/sets и фиксирует границы подтверждения. `crm/web/src/styles.css` импортирует локальные токены и связывает семантические `--crm-*` с ними, например ink, page, surface, border и accent. После A69 общие кнопки используют размеры m из сохранённых Atomaro-токенов; нейтральная контурная кнопка использует их default/hover/active значения вместо локальной серо-фиолетовой палитры. При этом CSS приложения построен на собственных React-компонентах и содержит также локальные значения. Текущий интерфейс использует Manrope; наличие Basis в сохранённом снимке не означает, что этот шрифт подключён или распространяется. Официальные Figma instances и прямая карта variable bindings не подтверждены. Навигационные иконки унифицированы в локальном SVG-компоненте `NavigationIcon` (`crm/web/src/nav-icons.tsx`); это элементы CRM, а не заявленные официальные иконки Atomaro. Знак бренда остаётся временным текстовым символом до подтверждённого бренд-ресурса.

По CSS-коду при ширине до 900 px навигация переходит вниз экрана, шапка и подписи уплотняются, очередь и формы перестраиваются, а карточка активности становится одноколоночной. При 390 CSS px действуют также правила до 420 px; нижняя навигация учитывает safe area. Для совмещённых ролей manager + admin она показывает три основных раздела и меню «Ещё» с остальными разрешёнными пунктами. Это описание правил исходников, не результат просмотра в браузере. Активная постановка требует проверить рабочие экраны при 1440, 1280 и 390 CSS px; такая runtime-проверка здесь не выполнялась.

Общее состояние [404 desktop](https://www.figma.com/design/kTMqGGpBwiPckoJk5VxCBo?node-id=200-5281) и [404 · 390 px](https://www.figma.com/design/kTMqGGpBwiPckoJk5VxCBo?node-id=201-5177) точечно прочитано через Figma design context. `web/src/main.tsx` и `.not-found*` в `web/src/styles.css` теперь используют одну карточку шириной до 480 px с отступом 16 px, заголовок Manrope 28/32, два коротких объяснения и контурную ссылку «В рабочее пространство»; на 390 px ссылка занимает ширину карточки. Это сверка одного состояния с двумя макетами, а не подтверждение всего интерфейса или runtime-адаптива.
